할 수 있는 것과 할 수 없는 것

check_circle 할 수 있습니다

  • check 안전서류(PDF/이미지) AI 분석 및 문제점 도출
  • check TBM 음성 녹음 → 전사 → 완전성 평가
  • check 현장 사진과 체크리스트 교차 검증
  • check 복사-붙여넣기, 패턴 부정행위 감지
  • check KOSHA 기준 객관적 위험도 점수 산출
  • check 검증 결과 PDF 리포트 생성

cancel 할 수 없습니다

  • close 실시간 현장 모니터링 (CCTV 대체 아님)
  • close 100% 정확도 보장 (AI의 한계)
  • close 손글씨/저화질 스캔 완벽 인식
  • close 인간 안전관리자 대체 (보조 도구)
  • close 오프라인 환경에서 사용
도전 과제

우리가 마주한 현실적인 어려움

01

OCR 정확도

손글씨, 저화질 스캔, 구겨진 서류 등 현장 문서의 인식 한계. 지속적인 모델 개선 필요.

02

현장 적용성

IT에 익숙하지 않은 현장 근로자를 위한 직관적 UX 설계. 교육 없이 사용 가능해야 함.

03

확장성

AI API 비용, 대규모 도입 시 인프라 문제. 온프레미스 배포 옵션 검토 중.
