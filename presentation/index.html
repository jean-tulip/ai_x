사고 근본 원인 우리 기능 어떻게 해결하나요?
1. 안전 교육 부족 TBM 완전성 평가 7개 항목 평가로 안전 주제가 실제로 다뤄졌는지 확인
2. 안전장비 미제공 사진 교차검증 AI 비전으로 PPE, 소화기, 안전난간 누락 감지
3. 안전조치 미이행 5단계 문서 검증 서명만 있는 게 아닌, 완전하고 논리적인지 검증
4. 위험한 작업조건 문서 내 논리검증 고소작업인데 안전대 미기재 등 22개 모순 탐지
5. 안전 불감증 행동 패턴 분석 항상 체크, 복사-붙여넣기, 급히 작성 패턴 감지
6. 규정 이탈 교차 문서 분석 30일간 타임라인 공백, 문서간 모순 탐지
7. 안전관리계획 부재 마스터플랜 검증 일일 보고서가 현장별 규정을 준수하는지 확인

도전 과제

우리가 마주한 현실적인 어려움

01

OCR 정확도

손글씨, 저화질 스캔, 구겨진 서류 등 현장 문서의 인식 한계. 지속적인 모델 개선 필요.

02

현장 적용성

IT에 익숙하지 않은 현장 근로자를 위한 직관적 UX 설계. 교육 없이 사용 가능해야 함.

03

확장성

AI API 비용, 대규모 도입 시 인프라 문제. 온프레미스 배포 옵션 검토 중.
